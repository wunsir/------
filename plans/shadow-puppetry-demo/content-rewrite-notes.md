# craft / reborn 内容重写说明

## 1. 目标

本说明仅用于指导 `craft` 与 `reborn` 两个支撑页的内容重写，不涉及首页 opening，也不涉及 `light-shadow` 首屏交互改造。

重写目标：

- 锁定两页为“真实内容支撑页”，不升级为与首页或王牌页竞争的主舞台。
- 明确哪些现有内容可保留、哪些必须替换、哪些需要降噪。
- 建立“真实案例优先”的内容来源策略，允许引入公开可考据资料作为锚点。
- 保留诗性表达，但诗性只能包裹信息，不能代替信息本体。

硬性边界：

- 不写实现代码。
- 不改仓库代码文件，除本规格文档外不落盘任何变更。
- 不新增类型体系。
- 不把 `craft` / `reborn` 做成百科资料库方案。

## 2. `craft` 在整站中的定位

`craft` 是“幕后工艺逻辑页”，职责是把“影人如何被做出来”讲清楚，为首页与 `light-shadow` 提供可信的工艺支撑。

定位锁定：

- 以真实工艺链路为主，不以概念叙事取胜。
- 以“材料到幕前结果”的因果关系为主，不做炫技型页面高潮。
- 动效保持 restrained polish，视觉权重明显低于首页与王牌页。

信息重心（必须强化）：

- 材料
- 雕刻
- 上色
- 组装
- 透光逻辑
- 关节逻辑

## 3. `reborn` 在整站中的定位

`reborn` 是“当代转译支撑页”，职责是解释皮影在今天如何被改写并继续成立，而不是制造第二个概念秀场。

定位锁定：

- 主线必须是“视觉再设计更新”。
- “传播方式更新 / 表演更新”作为辅助线，不反客为主。
- 案例必须可追溯、可解释、可被验证，避免空泛趋势表达。

优先顺序（固定）：

1. 视觉再设计更新（主）
2. 传播方式更新（辅）
3. 表演更新（辅）

## 4. `craft` 内容重写重点

主线组织建议：

1. 材料：皮料来源、处理步骤、厚薄分区与透光基础。
2. 雕刻：刀法类型、纹样功能、镂空密度与受光层次。
3. 上色：颜料与上色层次、色层与透光的平衡关系。
4. 组装：关节连接方式、操纵杆关系、动作可动范围。
5. 透光逻辑：不同部位厚薄与纹孔如何影响幕前亮度与边缘清晰度。
6. 关节逻辑：头、臂、腰、器械的联动关系如何决定“抬手、转身、亮相”的可读性。

现有内容处理建议：

| 区块 | 处理方式 | 说明 |
| --- | --- | --- |
| 工艺时间线结构（从制皮到组装） | 可保留 | 结构已经符合工艺链路，可继续使用。 |
| `craftLayers` 的四层拆解思路 | 可保留并强化 | 需要补入更具体的“透光/关节”事实描述。 |
| 时间线中“登场/退场”抒情段 | 降噪 | 保留少量舞台感，但减少篇幅，避免抢走工艺主体。 |
| 角色命名如“精雕青衣/重彩黑脸/提线武将” | 替换或半替换 | 建议改为“流派/工艺特征 + 行当”命名，减少拟人化概念词。 |
| 幕后场景命名如“匠作录/结骨录” | 替换 | 可改为真实工序案例或真实剧团工坊场景标题。 |

## 5. `reborn` 内容重写重点

主线组织建议：

1. 视觉再设计更新（主轴）：
   - 轮廓与剪影提纯
   - 纹样与结构的当代图形化
   - 材料与媒介替换后的视觉识别保持
2. 传播方式更新（辅助）：
   - 从戏台到展陈、短视频、教育活动、品牌合作的入口迁移
3. 表演更新（辅助）：
   - 与当代剧场、多媒体舞台、空间装置协同的演出关系变化

现有内容处理建议：

| 区块 | 处理方式 | 说明 |
| --- | --- | --- |
| `rebornTracks` 三轨结构 | 可保留 | 结构正确，需把“视觉再设计”信息量拉高。 |
| 时间线“视觉解构”方向 | 可保留并落地 | 需替换抽象词为可验证的做法与案例。 |
| 角色命名如“无相武将/流光青衣/矩阵巨灵” | 默认替换 | 概念化、虚构化过强，不利于真实性。 |
| 案例名如“《皮影·无界》/《镜花水月》” | 默认替换 | 若无法提供公开可考据来源，应替换为可验证案例。 |
| “参数化生成/交互算法化操纵杆”等表达 | 降噪或替换 | 保留技术方向描述，但必须有真实场景锚点。 |

## 6. 建议淘汰的命名类型

- 赛博化、未来学口号式命名。
- 过度拟构的“概念展标题体”命名。
- 脱离文化语境的巨物化、神话化命名。
- 无法给出公开来源的“自造案例名”。
- 只强调氛围、不指向对象与动作的抽象名词串联。

默认规则：现有内容中凡“过概念化、过虚构化、赛博化”的命名，允许直接替换。

## 7. 建议保留或可接受的命名类型

- 工艺对象 + 动作：如“牛皮刮制”“镂空起纹”“薄敷重彩”。
- 结构对象 + 功能：如“腕关节联动”“头杆控制点”。
- 流派/地域 + 行当或工艺特征：如“华县风格旦角纹样样本”。
- 场景 + 真实载体：如“博物馆展陈中的皮影轮廓再设计”。
- 当代案例命名采用“机构/场景/媒介 + 皮影转译点”的组合表达。

可接受文风：

- 可以诗性，但必须先给对象与动作，再给情绪。

## 8. 真实资料优先级

资料优先顺序：

1. 官方与权威来源：国家/地方非遗名录、文博机构公开资料、学术出版。
2. 一手实践来源：传承人访谈、剧团公开讲解、纪录片与展览说明。
3. 当代应用来源：高校/设计机构/品牌公开发布的可溯源合作案例。

每条内容建议至少具备一个“真实锚点”：

- 明确对象（流派、工艺步骤、机构、展陈、剧目或项目）。
- 明确可追溯出处（公开页面、出版物、展签、报道或访谈）。

适合后续补入的资料类型：

- 工艺步骤图解（材料处理、刀法、上色、组装）。
- 关节结构示意与操纵逻辑图。
- 幕前效果对照（未透光 / 透光后）。
- 当代视觉转译前后对照（原始纹样 / 再设计版本）。
- 机构化展陈与演出项目的公开说明文本。

## 9. 文案禁忌

- 禁止用概念词堆叠替代信息。
- 禁止“空诗性”文案连续出现而无事实落点。
- 禁止无来源的“伪案例”“伪机构”“伪项目”。
- 禁止高频方案腔与 AI 式整齐句法泛滥。
- 禁止把 `craft` / `reborn` 写成主舞台宣言。

允许与鼓励：

- 诗性句可保留为开场句或收束句。
- 信息句必须承担主体信息，且可被核验。

## 10. 每页建议模块数与内容密度

建议保持两页均为 4 个主模块，不扩容到大型资料库。

`craft` 建议：

- 模块数：4
- 推荐结构：工艺链路 / 角色-工艺样本 / 幕前结果片段 / 层次拆解
- 每模块卡片数：2 到 4
- 每卡建议正文：60 到 120 字
- 全页建议总字数：900 到 1300 字

`reborn` 建议：

- 模块数：4
- 推荐结构：更新链路 / 视觉再设计案例（主） / 传播与表演案例（辅） / 三轨收束
- 每模块卡片数：2 到 4
- 每卡建议正文：60 到 120 字
- 全页建议总字数：850 到 1200 字

密度控制原则：

- 不空：每个模块至少有一个可核验事实点。
- 不抢戏：每页只允许一个“记忆句群”，其余以信息句为主。

## 11. 后续实现建议

实现阶段建议按以下顺序执行：

1. 建立“现有文案清单”并标注三类状态：保留 / 替换 / 降噪。
2. 建立“真实锚点清单”，先补 `craft` 六大工艺要点，再补 `reborn` 三轨案例。
3. 先完成事实句重写，再补诗性包裹句，避免先写气质后补信息。
4. 统一命名风格，先删除概念化命名，再补可考据命名。
5. 最后做密度压缩，确保两页可读但不抢首页与王牌页。

实现约束重申：

- 不新增路由。
- 不新增业务类型体系。
- `craft` / `reborn` 保持支撑页层级。

## 12. 测试与验收标准

内容验收清单：

1. 仅 `craft` / `reborn` 内容被重写，首页 opening 与 `light-shadow` 首屏交互未被误改。
2. `craft` 文案明确覆盖：材料、雕刻、上色、组装、透光逻辑、关节逻辑。
3. `reborn` 文案以“视觉再设计更新”为主，传播更新与表演更新为辅。
4. 现有概念化、虚构化、赛博化命名已清理或替换，并可说明替换依据。
5. 每个模块至少具备一个可追溯真实锚点，不出现无法核验的核心案例。
6. 文案仍有诗性，但不存在“飘、空、靠概念词支撑”的段落。
7. 模块数量和字数密度符合“支撑页”标准，不形成与王牌页竞争的高潮结构。
8. 页面内容可在常规浏览时被快速吸收，不演变为百科式堆料。

通过标准：

- 读者能明确感知 `craft` 在讲“怎么做成”，`reborn` 在讲“如何当代转译”。
- 两页完成支撑叙事职责，同时保持整站层级：首页与 `light-shadow` 仍为最高权重。
