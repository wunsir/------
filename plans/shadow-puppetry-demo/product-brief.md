# 皮影戏非遗专题网站 Demo 产品需求文档

## 1. 项目概述

- 项目名称暂定：`一戏入影`
- 项目类型：`中国非遗主题前端网站 Demo`
- 产品形态：`年轻化互动专题网站`
- 实现范围：`仅前端，无后端`
- 目标受众：`招聘方 / 面试官`

## 2. 产品定位

这是一个以`皮影戏`为主角的非遗主题前端作品，不追求做成大而全的资料平台，而是通过更年轻、更沉浸、更具舞台感的表达方式，让用户在短时间内直观感受到：

`皮影戏很酷。`

产品需要同时体现以下能力权重：

- `视觉设计 40%`
- `交互设计 40%`
- `产品思维 20%`

## 3. 产品目标

### 3.1 核心目标

- 让用户第一眼就建立对`皮影戏`的强记忆点。
- 让面试官快速感知作品的审美、交互表达和信息组织能力。
- 通过专题化表达，将皮影戏呈现为一种`仍然可以被当代重新感知与再创造`的文化内容。

### 3.2 体验目标

- 整体体验应更像`被策展过的数字展览`，而不是普通内容网站。
- 网站应具备明确的开场、导览、高潮和延展关系。
- 视觉和交互都应服务于叙事，而不是堆砌特效。

## 4. 用户与使用场景

### 4.1 目标用户

- 主用户：浏览作品集的`招聘方 / 面试官`

### 4.2 典型场景

- 用户通过作品入口进入网站首页，在较短时间内浏览首页与若干分主题页。
- 用户希望快速判断候选人的：
  - 审美与视觉控制力
  - 前端交互表现力
  - 页面结构与产品组织能力

## 5. 内容策略

### 5.1 主内容策略

- 采用`一个主角 + 少量延展`的结构
- 主角为：`皮影戏`

### 5.2 延展策略

延展内容采用以下组合方式：

- `与皮影戏相关的戏曲 / 民间艺术联动`
- `传统元素进入当代设计的案例延展`

延展内容始终作为配角，服务于皮影戏主叙事，不喧宾夺主。

## 6. 视觉与内容基调

### 6.1 视觉人格

- 主风格：`暗场光影感`
- 辅助气质：`东方戏台感`

整体视觉应强调：

- 剪影
- 透光
- 投影
- 幕布
- 舞台空间
- 局部暖光点亮

应避免将站点做成传统大面积国风装饰页面。

### 6.2 文案语气

文案整体采用：

- `诗性 / 电影感`表达

要求：

- 保留专题感和情绪调性
- 不写成大段空泛抒情文案
- 兼顾可读性与信息传达效率

### 6.3 内容真实性要求

- 内容尽量对应`真实皮影戏资料与流派`
- 即使是概念型 Demo，也应避免明显失真或随意拼贴
- 在视觉再设计和当代表达中，仍需保留对真实文化语境的尊重

## 7. 信息架构

网站采用：`首页 + 3 个分主题页`

页面结构如下：

- `首页`
- `制作工艺`
- `光影美学`
- `当代新生`

## 8. 页面定位

### 8.1 首页

首页定位为：`总导演页`

职责：

- 完成开场仪式
- 建立整站情绪和视觉基调
- 承担分主题导览与节奏分发
- 承载少量核心内容，但不抢王牌页风头

### 8.2 制作工艺

突出皮影制作过程中的：

- 材料
- 雕刻
- 上色
- 组装

重点感受：

- 手作感
- 工艺层次
- 细节精度

### 8.3 光影美学

定位：`王牌分主题页`

核心体验定义：

- `三者都有，但以灯亮影现为主`

包含的体验维度：

- `灯亮影现`
- `幕布之后`
- `万象成影`

目标是把皮影戏最迷人的“光、幕、影、人”关系做到最强。

### 8.4 当代新生

表达方向为：

- 传播方式更新
- 表演形式更新
- 视觉再设计更新

其中：

- `以视觉再设计为主`

目标是让用户感受到皮影戏不是被封存的旧东西，而是可以进入今天视觉语境的活内容。

## 9. 浏览路径与叙事节奏

### 9.1 浏览路径

整体浏览路径采用：

- `导演式引导为主，兼顾自由浏览`

要求：

- 首页先带用户进入状态
- 用户随后可以自由选择分主题浏览
- 首页与导航需承担“导演镜头”作用，帮助用户建立推荐顺序和重点

### 9.2 首页体验链路

首页开场链路定义为：

`拉开幕布 -> 戏台展开 -> 主角影人登场 -> 进入专题导览`

其中：

- 首页进入仪式：`拉开幕布`
- 第一屏表现：`整座光影戏台展开为主，带一点主角影人登场`

### 9.3 首页导览方式

分主题入口采用：

- `展陈式入口卡片为主`
- `结合章节式引导`

目标：

- 让用户直观看到三个分主题的气质差异
- 同时保持推荐顺序和叙事节奏

## 10. 功能范围

产品采用：`中功能型`

在基础内容展示之外，必须具备以下模块：

- 搜索 / 筛选
- 时间线
- 角色卡片
- 剧目卡片
- 互动彩蛋

## 11. 核心功能定义

### 11.1 搜索 / 筛选

功能范围：

- 围绕`角色 + 剧目`展开
- `以角色为主`

功能定位：

- 兼顾内容组织与产品感
- 但整体`以展示感为主`

目标：

- 让用户感觉这不是只有视觉包装的专题页
- 同时不让工具性压过整体氛围

### 11.2 角色卡片

形式定义：

- `人物图鉴 + 戏剧角色档案`
- `以人物图鉴为主`

目标：

- 先以视觉形象吸引用户
- 再补充角色身份、气质、出场剧目等信息

### 11.3 剧目卡片

形式定义：

- `故事入口 + 舞台场景入口`
- `以舞台场景入口为主`

目标：

- 让用户先被某个剧目的舞台瞬间吸引
- 再理解剧目的故事背景与角色关系

### 11.4 时间线

形式定义：

- `历史演变 + 一场戏的发生时间线`
- `以一场戏的发生时间线为主`

目标：

- 让用户理解一场皮影戏如何从幕后准备到正式落幕
- 历史线作为补充，不喧宾夺主

### 11.5 互动彩蛋

形式定义：

- `视觉反馈 + 轻操作`
- `以视觉反馈型为主`

可承载方向包括：

- 悬停发光
- 幕布轻晃
- 影子摆动
- 灯光反馈
- 局部轻操作触发

目标：

- 强化记忆点
- 增强沉浸感
- 避免将专题页做成偏玩法的互动游戏

### 11.6 延展内容

角色定位：

- 非主叙事入口
- 用于建立更大的文化关联和当代设计关联

目标：

- 帮助用户理解皮影戏在非遗体系中的位置
- 帮助用户理解传统元素如何被重新设计和传播

## 12. 优先级策略

整体策略采用：

- `首页 + 一个王牌分主题最强，其余两页稳定支撑`

优先级分配如下：

- 第一优先级：`首页`
- 第一优先级：`光影美学`
- 第二优先级：`制作工艺`
- 第二优先级：`当代新生`

## 13. 音效策略

允许将以下内容作为体验组成部分：

- `环境音`
- `戏台音效`
- `鼓点`

音效在产品中的作用：

- 增强开场仪式感
- 强化舞台氛围
- 辅助转场和节奏变化

约束：

- 音效必须服务体验，不可喧宾夺主
- 需要保留用户可控性，不应造成打扰

## 14. 非目标

本项目不包含：

- 后端能力
- 用户账号体系
- 真实收藏 / 预约 / 社交业务
- 大而全的非遗百科平台
- 以知识完整性为首要目标的资料库

## 15. 产品验收标准

如果产品达标，用户应形成以下感受：

- 第一眼能记住“这是皮影戏，而且很酷”
- 页面不是模板站，有明显主题辨识度
- 网站结构完整，不只是单页海报
- 交互和视觉围绕叙事服务，而非单纯堆动效
- 作品能体现候选人的视觉控制力、前端交互表现力和产品组织能力

  - 基于本 PRD 和方案稿拆解页面、组件、动效与实现优先级
